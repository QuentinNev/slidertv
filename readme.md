# Slider TV
Sliver TV permet d'afficher la météo, des news et des slides customisées aux utilisateurs sur le support de leur choix via une URL.

# Techs
## Backend
- Adonisjs 7
## Frontend
- React 19
## Adapter
- Intertia
## Database
- Lucid ORM
## Auth
- Session-based auth with secure cookie storage
## Styling
- Custom CSS with modern features (OKLCH colors, CSS variables)
## Build
- Vite
## Validation
- VineJS
## Type Safety
- Tuyau
## UI Components
- Sonner
## Testing
- Japa
## Typescript
- Full TP support with strict mode enabled
